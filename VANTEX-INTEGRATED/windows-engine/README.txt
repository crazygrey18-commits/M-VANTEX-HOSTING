M VANTEX HOSTING V5 — LOCAL ADMINISTRATION
Extract all files, then double-click START-VANTEX.bat. Requires existing Node.js 18+; no npm packages. Keep the console open. Alternate launcher uses port 3781 if 3780 is occupied. Do not expose this admin panel to the internet.
Create an instance, then open servers\INSTANCE in File Explorer. Extract official Windows FXServer artifacts there (FXServer.exe must be directly inside). Add server resources and edit server.cfg with unique TCP/UDP ports and your own Cfx license. Start from dashboard. Process running does not prove FiveM is accepting players. Stop terminates process, so issue appropriate save/shutdown commands first. Backups are local directory copies, not offsite backups; stop before creating one. File panel lists root files; use Explorer for uploads/deletions. Do not place untrusted artifacts or symlinks/junctions inside instance folders. Only trusted local administrator intended. No public customer authentication, isolation, billing, automatic artifact downloads, Vercel link or txAdmin provisioning. Windows and real FiveM require testing. Existing V3/V4 data is not migrated automatically.
