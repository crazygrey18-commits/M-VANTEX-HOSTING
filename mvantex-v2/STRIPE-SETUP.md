# VANTEX sandbox checkout
Deploy this mvantex-v2 folder as the Vercel root. Set STRIPE_SECRET_KEY to a newly rotated sandbox sk_test_ key; do not commit it. Set VANTEX_SITE_URL to the exact deployment origin (no trailing slash), default https://vantex-smoky.vercel.app. Redeploy. Open /fivem and click Stripe test checkout. Use Stripe test card 4242 4242 4242 4242, future expiry, any three-digit CVC. Check Stripe sandbox for the subscription and cancel it after testing.

Price mapping in lib/plans.ts assumes the seven IDs after Starter were supplied in descending tier order. The API verifies active sandbox price, USD amount, monthly interval, active product and matching tier word before checkout. Fix mapping if verification fails. No live payments, webhook, authentication, durable orders or provisioning are implemented. The existing browser demo remains separate. Do not use for commercial sales. The uploaded repo includes an older duplicate in VANTEX-INTEGRATED; only the deployed root mvantex-v2 is included in this update.
